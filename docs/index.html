CHAPTER II / THE MECHANICS

TURN UP
THE HEADROOM.

Turbo gives eligible CPU cycles a shorter divider. It doesn't change the video refresh rate or make every game 50% faster.

ROM reads can still wait on memory. Timing-sensitive games may behave differently. The stock-speed setting is always one menu away.

CHAPTER III / ARRIVAL INSTRUCTIONS

LOAD. TWEAK. PLAY.

PLEASE MAKE YOURSELF AT HOME.
  1. 01

    KEEP A BACKUP.

    Keep a copy of your stock TurboGrafx RBF. Copy the experimental RBF into _Console and launch it.

  2. 02

    SET YOUR PACE.

    Open Hardware → CPU Turbo. Start at +20%, then compare +50%. Extra sprites are enabled by default. Select Normal if you want the original sprite limit.

  3. 03

    HIT A BUSY SCENE.

    Try the same Ninja Spirit scene at Off and turbo. Compare slowdown, sound, controls and stability. Return to Off if issues appear.
