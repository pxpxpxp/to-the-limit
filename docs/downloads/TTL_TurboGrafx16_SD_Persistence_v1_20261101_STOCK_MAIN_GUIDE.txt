INSTALL / FIRST TEST
1. Back up the card, original RBF, saves and savestates. Prefer a test card.
2. Keep your stock card-root MiSTer binary. Copy the release RBF to _Console.
3. Use disposable progress in a uniquely named Ninja Spirit .pce, normal
   SDRAM HuCard mode, default clocks, no cheats, CD, SNAC, MB128, SuperGrafx
   or special devices. This is not a claim of all-HuCard or CD support.
4. Set ROM Data Swap before loading. If changed afterward, reload the ROM
   and discard any states made between the change and reload.
5. Start fresh: old experimental state formats are incompatible. Back them
   up separately; do not overwrite your only good progress.
6. Test each of the four slots, then verify reload using disposable progress
   before relying on persistence. Do not reset, switch ROM/core, repeat slot
   actions or cut power while a save is being processed.

STOCK MAIN SAFETY LIMITS
The current RBF has a legacy OSD line "Wait for Saved to SD in Main".
That legacy instruction does not apply on stock Main; no such notification
is available.
Stock's "Saving the state" message appears BEFORE the file write and is
not a completion acknowledgement.
Stock does NOT emit a "Saved to SD" message. Do not wait for
a message that will not appear. Capture completion is NOT confirmed SD
completion. There is no fixed number of seconds that guarantees durability.
Use normal shutdown rather than abrupt power removal and verify reloads.
Stock marks the generation before writing: failed writes are not retried
automatically for that same generation. After resolving a storage problem,
a fresh save generation is needed; don't trust an earlier failed save.
Stock accepts payloads without TG-specific host CRC validation. The tested
host uses O_SYNC temporary-file writes and rename, but does not sync the
parent directory. Card/stack behavior and abrupt power loss remain risks.
No full CDC closure or real concurrent ARM/FPGA memory-race guarantee.
